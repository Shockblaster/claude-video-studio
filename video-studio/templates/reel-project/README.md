# Reel project template (9:16, one-take world + talking avatar)

The structure of a real 80 s finance reel that a client approved ("its amazing"), with its brand and disclaimer
removed. It is a starting point to adapt, not a fill-in-the-blanks generator: replace the cards, data, cue names
and colours with your own story.

## Files
```
index.html                 root: world (track 1) + avatar video (track 2) + fx grain (3) + captions (4) + voice (5)
hyperframes.json           HyperFrames project config
compositions/world.html    the one-take world: station cards, a hero coin that hops card to card on spoken words,
                           a camera that eases between card framings, real-data line charts, a pull-out reveal
                           under the disclaimer card, and a dive back to card 1 for the loop. One pure render(t).
compositions/fx.html       seeded film grain
compositions/cap.html      (generated by scripts/pipeline/build_timing.py)
assets/timing.js           named cue times (generated by build_timing.py); world.html reads window.__T.w.<name>
assets/nifty.js            example REAL data: NSE Nifty 50 daily closes (2020 and 2026), fetched Oct 2026
pick.html                  by-ear pick page for pronunciation, voice speed and music
```
Add your own: `assets/fonts/` (copy `InterVariable.woff2` from the skill's `assets/fonts/`, or your brand's font),
`assets/audio/vo.wav`, `assets/video/avatar.webm` (from `scripts/pipeline/render_chunks.py --join`),
`assets/img/logo.png`, and optionally `assets/img/backdrop.jpg` (a soft blurred AI plate behind the presenter).

## Build order (each step's tool is in the skill's `scripts/`)
1. `sources.md` first: every on-screen number with a primary-source link and date.
2. Script: one spoken line per row in `vo/lines.txt`. Make the pick page for tricky words, then the voice:
   `python -I scripts/pipeline/build_vo.py --lines vo/lines.txt --out vo` and
   `python -I scripts/pipeline/words.py --vo vo`.
3. Mouth: `python -I scripts/mouth_rhubarb.py --lines-dir vo/lines --starts vo/starts.json -o avatar/mouth.json`.
4. Avatar plan (one pose per line, each with its "why"), then render in chunks:
   `python -I scripts/pipeline/render_chunks.py ... --chunk N` for each N, then `--join`. Read every frame of
   `preview.mp4` and run `scan_avatar.py`.
5. Measure the avatar-free caption box over all avatar frames. Then build the cues and captions:
   `python -I scripts/pipeline/build_timing.py --words vo/words.json --cues cues.json --hf . --end <s> --box x,y,w`.
6. Edit `compositions/world.html` (cards, data, cue names, hops), snapshot key beats
   (`npx hyperframes snapshot --at ...`), then `npx hyperframes check --json` until there are 0 errors.
7. Draft render (segmented, foreground):
   `HF_SEGMENTED_CAPTURE=true npx hyperframes render --quality draft --workers 2 --resume --keep-segments -o out/draft.mp4`.
8. QC every frame (`scripts/pipeline/sheets.py`), `scripts/qc_reel.py`, and `scripts/pace_check.py --mask <avatar box>`.
9. Sound: `scripts/pipeline/mix.py` with an `sfx.json` (every hop lands a note, every stamp a hit).
10. Phone review, delivery render, a final QC, and a PSNR check against the approved draft.

## What the reviewers corrected on the original (avoid these)
- Neighbouring cards showing faintly behind the presenter read as clutter: only the framed card shows.
- An open palm was cut at the avatar box edge: size the box on the widest pose.
- Poses that point off-screen or hang a prop below the frame: drop them.
- The lips separated at the corners on open mouths: rebuild the face rig with the lip-seal fix and read
  `mouth_zoom.png`.
