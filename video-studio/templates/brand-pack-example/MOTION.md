# Larkspur: motion system (FICTIONAL example)

## Colour
| Token | Hex | Use |
|---|---|---|
| leaf | #2F6B4F | Primary: headlines, key shapes |
| leaf-deep | #1E4634 | Depth, shadows |
| cream | #F6F1E7 | Default background (light, warm) |
| ink | #24261F | Body text |
| saffron | #E9A93B | THE highlight: caption key word, marker sweeps, the climax number |
| clay | #C0654A | Warnings, "too hot", mistakes |
| mint | #8FC3A4 | Secondary shapes, chart series 2 |

## Type
- Headlines and captions: Inter (bundled with video-studio, OFL), weight 700-850.
- Sizes on 1080 wide: hook 110-150 px, headline 80-110, captions 52-56, labels 30-36, never under 28.
- Numbers with tabular figures.

## Motion personality
Calm and warm, then a crisp snap on the payoff (a stamp, a counter landing). Springs with gentle overshoot
(back.out 1.3-1.6) for arrivals; slow camera drift so nothing is ever dead still; one soft glow on the key element.

Allowed: steam particles, liquid pours, leaf morphs, ingredient cards, count-ups, the presenter pointing.
Banned: dark sparse frames, neon, fake product UI of real apps, stock "money rain"-style clichés.

## Captions
2-4 words, white on an ink pill (rgba(36,38,31,.86)), key word in saffron, in the avatar-free box, never over a face.

## Sound
Soft acoustic or lo-fi beds (licensed, logged). SFX: pour, clink, steam hiss, a soft ding on each tip.
